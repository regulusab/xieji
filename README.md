# 協紀擇日

https://regulusab.github.io/xieji/

以天干地支、陰陽五行為本的擇日選時網站。純前端靜態網站（GitHub Pages），不收集資料、無廣告。

## 第一期（MVP）功能

- 萬年曆日頁：當地農曆、日家干支、節氣（地方平時）、建除十二神、黃道黑道、二十八宿、紫白九星（年月日）、沖煞、旬空、彭祖百忌、胎神占方、吉神凶煞列表。
- 吉時表：十二時辰加晚子時，時干支、時家黃黑道、時家紫白、日祿歸時、天乙貴人、截路空亡、旬空、五不遇時、日破。
- 月曆：干支、建除、黃黑道、節氣；可依事項標示等級。
- 區間擇吉：事項（訂婚、嫁娶、開市、簽約、入宅、移徙、動土、修造、安床、安葬、出行、剖腹生產擇時）＋日期範圍（三年內）＋相關人生日 → 排序候選日與建議時辰；理由可展開，附出處。一般模式只顯示等級，專業模式顯示分數。
- 分享連結（URL 參數，不含姓名）、iCal 匯出、列印、存檔（localStorage）與 JSON 匯出入、說明文庫。

## 曆法基準（老師 2026-11-19 裁定）

- 時間一律為使用者自行換算的地方平時，照寫使用（不加減夏令，不做時辰邊界警告）。
- 節氣、合朔換算為地點經度的地方平時：世界時＋經度×4 分鐘，不含夏令。
- 農曆以當地合朔所在日為初一，月序、閏月依中國農曆；農曆日一律重算。
- 東經 70° 以西日柱干支進一位（日期不動）：只有日柱干支進一位，時干依五鼠遁重推；年、月柱仍以原地方平時對當地節氣。
- 子時換日預設 0:00，可切換 23:00。
